# v0.141.0 — Triple-Keyed Provenance in Graph-Scoped Justify (VAL-391)

Cross-tenant copies of a derived fact justify with the same proof tree as
the recording graph, as long as the asking graph holds every antecedent.

## Defect

`build_proof_tree_graph` (`src/datalog/derivations.rs`) resolved
`_pg_ripple.derivations` strictly by the caller's graph statement ID. A
graph holding an **asserted copy** of a derived triple (same s/p/o, its own
SID, no derivation row) justified as `base` forever — even when it held all
the antecedents of the recorded rule application — because:

1. `derivations_for_sid(caller_sid)` returned nothing (the recorded rows
   hang off the recording graph's SID), and
2. antecedent validation matched the recording graph's SIDs against the
   asking graph (`sid_in_graph(foreign_sid, g)`), which can never hit.

Evidence: ValorBrain VAL-187 / VAL-391 — tenant graphs mirror derived
conclusions (`kg/indirectly_runs_on`); `kg_explain` answered `unverified`
for the copy while the original answered `inferred`. The initial suspicion
("the derivation is lost after the first read / delta promotion discards
it") did not hold: `merge_predicate` preserves `i`, derivations survive
merges and repeated reads; the failing reads were always the copy in the
other graph.

## Fix

When a node's own row carries no derivation rows, the graph-scoped builder
falls back to derivation rows recorded for **any materialisation of the
same logical triple** (`sids_for_triple_any_graph`), and rebuilds each
branch with antecedents re-resolved inside the caller's graph
(`antecedents_in_graph` → `sid_for_triple_in_graph`):

- Graph holds conclusion + all antecedents → `inferred` tree with the
  asking graph's own SIDs; no re-inference needed.
- Graph holds only the conclusion (or near-miss antecedents) → `base`
  bare proof, exactly as before — an incomplete tree is never returned, so
  the VAL-201 leak rule is preserved (the tree only ever names triples the
  asking graph already holds; rule identity/text is global catalog data).

The same-graph path and the graph-blind 3-arg `justify()` are unchanged.

## Regression

`tests/pg_regress/sql/v0147_justify_cross_graph.sql` (VAL391-1..5):
recording graph still infers; conclusion-only graph stays `base`;
conclusion + antecedents infers with own SIDs; near-miss antecedents stay
`base`; repeated reads stay `inferred`.
